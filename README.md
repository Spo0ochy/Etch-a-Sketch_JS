# Etch-a-Sketch_JS

## Description

This etch-a-sketch project was part of [The Odin Project](https://www.theodinproject.com/lessons/foundations-etch-a-sketch) curriculum.

The goal here was to practice Javascript, particularly the `for` loop to generate the screen size dynamically and use `addEventListener` to change the state of each pixel.

Live demo here (you should use it with the browser **chrome on a computer** for a better output).

## Features

The [etch-a-sketch](https://en.wikipedia.org/wiki/Etch_A_Sketch) is a little toy that permits drawing on a white board by controlling two axes (vertical and horizontal).

The controls are a little bit different here cause of the hardware. The **cursor will act as the brush** and just by hovering the pixel, you will change their state.

There are four mods:

1. **Brush**, to turn a pixel to black,
1. **Erase**, to turn a pixel to white,
1. **Colorful**, to turn a pixel to a random color,
1. **Pencil**, to turn a pixel to but *gradually*, you will have to go back if you to darken it more and more.

You can also choose the **screen size**. The resolution vary from 2x2 pixels to 100x100 pixels.

*By default* you will be set on **brush mod with a 5x5 pixel canva**.

## UI

Even if we know the etch-a-sketch for its **iconic red**, you will se that the design here looks like the one of a *gameboy*...? Why ?

The design here is inspired by another version of the product, the *Etch-a-sketch animator*. The same principle as the first one, but with some electronics built-in, you can create some animations with it. And so, it has the same look as the original gameboy (maybe because it was a trend at the time, I don't know).
